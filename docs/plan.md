## 目的と成功の基準

WorldOS風のAI駆動の世界シミュレーションを、自分専用・ブラウザ（PC/スマホ）・0円で作る。エンジンは1本、世界は差し替え可能なデータ（世界パック）。

- 1日50ターン程度遊んでも無料枠に収まる
- 100ターン以上進めても設定・人物・数値が矛盾しない
- 3つ目の世界はデータ追加だけで足せる
- スマホで片手で遊べる（入力・閲覧・セーブ）

## 中核設計

### 1ターンの流れ

1. プレイヤーが行動を自由入力（または候補を選ぶ）
2. コードが「世界設定・現在の状態・直近の展開・要約・登場キャラ記憶・隠し筋書き」を組み立ててAIへ
3. AIは物語本文と状態変更の提案をJSONで1回で返す
4. コードがJSONを検証し、許可された操作だけを上限・下限・ルールに沿って適用
5. 戦闘・判定など数値で決まる部分はコードが計算（AIは描写のみ）
6. 保存し、ストーリーカードと各部品を更新

### 記憶の階層

| 層 | 中身 | 毎ターン渡すか |
| --- | --- | --- |
| 世界設定 | 世界観・ルール・描写方針（固定） | 渡す（キャッシュ対象） |
| 現在の状態 | 数値・フラグ・日付・所在など（JSON） | 渡す |
| 直近の展開 | 最新5ターン程度の本文 | 渡す |
| 要約 | それ以前の展開の圧縮 | 渡す（10ターンごと更新） |
| キャラ記憶 | キャラごとの「覚えていること」 | 登場キャラ分のみ |
| 隠し筋書き | 見せない伏線・今後の展開 | 渡す（非表示） |

### 世界パック

世界観文書、初期状態、ステータス定義、キャラ一覧（人物カード）、イベント表、ルール、使う部品、描写方針。エンジンはこれを読むだけで動く。

### 送信量の目安

1回あたり約8,000〜10,000トークン（世界設定3,000、状態2,000、直近の展開3,000、出力800前後）を上限の目安にする。

## 無料AIの運用

- 主力：Gemini API無料枠。モデルは設定で1つ選ぶ（既定3.8 Flash、ほかに3.6 Flash・3.5 Flash-Lite・Gemma 4）。自動切替はしない。上限はAI Studioで確認
- 見込み：1モデル1日250〜1,500回程度（第三者報告）。1ターン1.1回なら1モデルでも約200ターン/日以上。枠切れ時は画面に表示し、設定で手動でモデルを変える
- 予備：MacのOllama（枠切れ時、要約など）。ブラウザからの接続許可設定が必要。スマホからは同一Wi-Fi経由
- 無料枠の入出力はGoogleの製品改善に使われ人が読みうる → 個人情報を入れない

## システム構成

サーバーなし。静的ホスティング＋ブラウザから直接Gemini＋IndexedDB保存。セーブは毎ターン自動（手動セーブなし）。APIキーは端末のブラウザにのみ保存。PC⇔スマホのセーブ移動はJSONの書き出し・読み込み（自動同期は第2段階）。

## 画面構成

PCは右サイドパネル、スマホは下部タブ。

- 物語：最新のストーリーカード、行動候補3つ、自由入力。過去カードはスクロール
- 状況：世界のステータス
- 人物：一覧・ステータス・関係性 → 個別チャットへ
- チャット：会話結果も状態に反映
- ニュース（第2段階）
- 記録：年表、実績、書き出し・読み込み、使用量メーター、設定（APIキー・接続先・モデル）

## 世界1：第二次世界大戦

- 立場：国家指導者（将校・記者・市民の視点は第2段階）
- プレイ可能：日本、ドイツ、イギリス、アメリカ、ソ連、フランス、イタリア、中国。登場：全世界（1939年時点の独立国と主要な植民地・保護領）
- 開始：1939年9月（1936年・1941年12月は追加候補）
- 1ターン：平時1か月、戦時2週間
- 地図：全世界を約100地域（主要国本土は細かく、他は粗く）
- 国家ステータス：工業力、陸海空軍、資源（石油・鉄鋼・食料）、国民士気、政治の安定、戦争疲弊、各国との関係（−100〜100）、支配地域
- 戦闘：戦力比・地形・補給・季節・乱数でコードが計算、AIは戦況報告
- 他国：普段は優先度表（ルール）。主要国の方針見直しは3ターンに1回まとめてAI。中小国は陣営への傾き（枢軸・連合・中立）と少数の数値のみ
- 史実イベント：条件付きで起きうる出来事として表で持つ（独ソ不可侵、フランス降伏、真珠湾など）
- 描写方針：戦争の悲惨さは描くが、虐殺・戦争犯罪をゲーム的報酬や目標にしない。安全フィルターで止まったら表現を抑えて再生成
- 初期データ：AIに下書きさせて資料で確認。初版は相対的な強弱が合っていればよい

## 世界2：ホグワーツ

- 時代：原作と同時代（1991年入学）。人物も原作どおり。プレイヤーはハリーたちの同級生
- 期間：入学から7年生の学年末（1998年）まで。開発は1年目から順に足す
- 1ターン：普段は時間帯単位（朝・授業・放課後・夜）。早送りで数日〜数週間飛ばし、原作の出来事や行事の前で止まる
- カレンダー：9月1日入学、ハロウィン、クィディッチ、クリスマス休暇、試験など
- ステータス：本人（科目別成績、体力、魔力、評判、規則違反、所持品・呪文）、寮点（4寮）、人物ごと（好感度・信頼・ライバル心・疑念）
- 原作の筋：原作に忠実な粒度の出来事表を「固定イベント」として持つ。何もしなければ原作どおり進む。プレイヤーは介入でき、ストーリーが分岐してよい。分岐後は後続イベントを前提条件で判定し、成り立たないものは起きないか形を変える
- 独自の謎：各学年の開始時にAIがプレイヤー独自の小さな謎と伏線を1回作り、隠し筋書きとして保存
- 人物カード：性格・口調・原作での立ち位置・初期関係。状態（生死・所属・関係）は出来事表に合わせて更新
- 7年目：ハリー・ロン・ハーマイオニーは不在。占拠下のホグワーツで過ごし、ホグワーツの戦いへ
- 自分専用で公開しない前提

## リスクと対策

| リスク | 対策 |
| --- | --- |
| 無料枠の縮小（2025年12月にも大幅削減） | AI接続を差し替え可能に、ローカルへ退避できるように |
| AIのJSON崩れ | スキーマ指定＋検証＋1回再試行、だめなら物語のみ表示 |
| 長期プレイでの矛盾 | 状態はコードが正、要約とキャラ記憶の定期更新、100ターン通しテスト |
| 安全フィルター | 描写方針を明記、止まったら表現を抑えて再生成 |
| ローカルモデルの品質 | 予備と要約用に限定 |
| データの扱い | 個人情報を入力しない |
| 作り込みすぎ | 縦切りを先に作る |
